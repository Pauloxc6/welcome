## Desenvolvimento

Para clonar o repositório:

```bash
git clone https://github.com/Pauloxc6/welcome.git
cd welcome
```

O projeto é composto por arquivos estáticos e não necessita de um sistema de build ou gerenciador de dependências.

Para executar localmente, você pode utilizar um servidor HTTP simples:

```bash
python3 -m http.server
```

Depois, acesse:

```text
http://localhost:8000
```
