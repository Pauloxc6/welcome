Política de Privacidade

Última atualização: 21/09/2026


1. Introdução

Esta Política de Privacidade descreve como suas informações pessoais e dados de navegação são tratados ao acessar e utilizar este site, incluindo as áreas públicas de artigos, catálogo de cursos, jogos e mercado. O compromisso aqui assumido preza pela transparência, privacidade e conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

2. Informações Coletadas e Processamento

A coleta de dados varia de acordo com o nível de interação com o site:


a) Visitantes e Usuários Comuns (Acesso Público): Não é necessário realizar cadastro ou login para visualizar artigos, cursos, projetos ou produtos do mercado. Coletamos apenas dados fornecidos voluntariamente via formulário de contato (nome, e-mail e mensagem) ou preferências mantidas localmente no navegador.


b) Autenticação Restrita a Administradores: O módulo de autenticação (Firebase Authentication) destina-se **exclusivamente a administradores** do site para acesso ao painel de gerenciamento de conteúdo. Dados de credenciais e tokens de sessão são processados estritamente para validar acessos administrativos autorizados.


c) Registros de Acesso (Logs): Informações técnicas coletadas automaticamente pelo servidor/CDN, incluindo endereço IP, tipo de navegador, sistema operacional e páginas visitadas para fins de segurança e diagnóstico.

3. Armazenamento de Dados em Banco de Dados (Firestore)

Os dados exibidos nas seções públicas (como cursos e artigos) ficam armazenados em um banco de dados NoSQL na nuvem (Google Cloud Firestore).


A estrutura do banco de dados conta com regras estritas de segurança: **a leitura é pública para consulta de conteúdos**, enquanto as permissões de **criação, edição e exclusão de dados são estritamente restritas a administradores autenticados**.

4. Formulário de Contato

As mensagens enviadas pelo formulário de contato são utilizadas apenas para responder às dúvidas, solicitações ou propostas enviadas pelo usuário. Essas informações não são compartilhadas com terceiros nem utilizadas para fins de marketing não solicitado.

5. Cookies e Métricas

Utilizamos cookies e tecnologias de medição para otimizar a experiência do site e contabilizar métricas anônimas de tráfego (Google Analytics).

6. Serviços de Terceiros e Segurança

Para manter a plataforma estável e segura, utilizamos serviços como GitHub Pages (hospedagem), Google Cloud / Firebase (banco de dados e autenticação administrativa), reCAPTCHA Enterprise (proteção contra bots) e intermediadores de pagamento em produtos e cursos.

7. Direitos do Usuário (LGPD)

Como titular, você pode solicitar a qualquer momento a confirmação da existência de dados enviados por você (via formulário de contato), a atualização desses dados ou sua exclusão definitiva.

8. Alterações desta Política

Esta Política de Privacidade pode ser atualizada periodicamente conforme novas funcionalidades forem integradas ao site. A data de atualização no topo desta página sempre indicará a versão mais recente.
