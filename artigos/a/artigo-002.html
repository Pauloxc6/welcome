Turtle ORM framework para bash

Última atualização: 17/09/2026

Nesse artigo irei mostrar meu projeto pessoal, que fiz para resolver minha necessidade de trabalhar com banco de dados utilizando Bash.


De onde surgiu a ideia?

A ideia surgiu de alguns projetos que precisei utilizar SQL justamente com bash. Mas recentemente estava estudando o Flask e o ORM Peewee, e vi que as facilidades que o Peewee proporciona no desenvolvimento com bancos de dados.

Alguns podem pensar qual é a necessidade de se trabalhar com SQL em bash? E eu digo: quando você precisar utilizar armazenamento persistente você pensará o contrário, fugindo do padrão de automação de instalação e configuração e construindo aplicações que fogem desse padrão, vai ter a necessidade de se utilizar um banco de dados.

É estranho pensar nisso em bash, mas às vezes precisamos pensar fora da caixa e fazer coisas mais diferentes.


Por que o nome Turtle?

Eu precisava de um nome interessante para esse projeto, de início, como eu queria um nome simples e que remetesse ao open source, olhando para minha mesa, vi meu livro de programação shell script, pensei shell -> casco/concha -> tartaruga. Foi bem isso.


Como funciona

Como mencionei a ideia é ser simples, eu usei o Peewee como base para o desenvolvimento. O Turtle surgiu com o objetivo de ser rápido e fácil de utilizar pensei em torná-lo o mais enxuto possível, para que qualquer pessoa possa utilizá-lo.

Você começa instalando a biblioteca em seu sistema, por padrão os arquivos são instalados no FHS (Filesystem Hierarchy Standard) do usuário em $HOME/.local/share para os arquivos do ORM e em $HOME/.local/bin para o binário principal que é importado dentro do seu projeto.

pauloxc6@github-pages

# Clone o repositório e execute o install.sh
user@db:~$ git clone https://github.com/Pauloxc6/turtle.git turtle
user@db:~$ cd turtle
user@db:~/turtle$ bash install.sh

# Run
user@db:~/turtle$ orm --version

# Importa a biblioteca no seu script Bash
source "/home/$USER/.local/share/turtle/orm.sh"


Após a instalação em seu projeto, você pode começar chamando o framework com o comando source e o caminho para o orm.sh.

O primeiro passo é difinir qual tipo de banco de dados será usado, vamos utilizar o sqlite, pois na data de publicação deste artigo, está na versão v1.0 e só tem suporte ao SQLite. Continuando, é iniciado utilizando o objeto SqliteDatabase seu uso é bem simples SqliteDatabase data.db.

Ao iniciar o objeto o próximo passo é criar as tabelas e definir suas colunas por meio das models. Para criar uma tabela, utilizamos o SqliteDatabase:create e para definir a model utilizamos Model:<TypeField>. Ex:

pauloxc6@github-pages

SqliteDatabase:create customers && BaseModel
Model:TextFiled customers name && BaseModel


  • Obs: O BaseModel é utilizado para fazer o processamento das models e dos fileds.
  • Tipos: Exitem vários tipos de fields, consulte a documentação para mais informações em Fields.


Depois de criar as tabelas e as colunas o prómixo passo é inserir e consultar os dados.


pauloxc6@github-pages

SqliteDatabase:insert customers name "Paulo Santos" && BaseModel
SqliteDatabase:select customers box


  • Obs: A saída pode ser modifcada através de <json,box,csv> informados como último argumento.


Por fim mostrarei como podemos apagar um registro e uma tabela, de forma simples e rápida.


pauloxc6@github-pages

SqliteDatabase:delete customers 1
SqliteDatabase:drop "customers"


Como foi mostrado, é bem simples de se trabalhar com esse ORM. Ele ainda está em fase de desenvolvimento tem muitas coisas para melhorar nele. Em breve, vou trabalhar mais nele, vou colocar o get que vai ser possível buscar um registro pelo id, e também suporte a outros bancos de dados como Mysql e Postgresql.
