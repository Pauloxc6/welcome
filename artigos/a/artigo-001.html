Ferramentas úteis com bash

Última atualização: 09/09/2026

Neste artigo irei mostrar o poder do bash em automações de tarefas de recon e enumeração de serviços.

O bash se torna poderoso nas mãos certas. Não existe a melhor forma de se escrever um código, mas sim aquele que funciona perfeitamente para você.


Brute force de subdomínios

Como início, mostrarei o mais básico que podemos fazer com bash: um simples brute force de subdomínios.

Mas antes, precisamos entender como funciona a estrutura de uma URL (Uniform Resource Locator):



  • Protocolo: Define as regras de segurança e comunicação para transferir os dados entre o navegador e o servidor (ex: https://).
  • Subdomínio: Um prefixo adicionado ao domínio principal para organizar ou separar seções específicas do site (ex: blog.).
  • Nome do domínio: O nome principal e exclusivo que identifica o seu site na internet (ex: example).
  • TLD (Domínio de Nível Superior): A extensão final do domínio que indica a categoria ou país do site (ex: .com ou .br).
  • Caminho: A rota completa dentro do servidor que direciona para onde a página ou arquivo está localizado.
  • Subpasta: O diretório específico dentro do servidor onde o conteúdo está armazenado (ex: /resources/).
  • Recurso: A página, arquivo ou slug final exato que está sendo acessado (ex: /new-example).
  • Parâmetros: Informações extras enviadas à página após a interrogação (?), usadas para busca, filtros ou rastreamento (ex: ?key1=value).
  • Ancoragem: Aponta para uma seção específica dentro da própria página usando o caractere cerquilha (#faq).

Após entendermos como funciona a estrutura básica de uma URL, vamos para nosso primeiro script:

pauloxc6@github-pages

#!/usr/bin/env bash

url="$1"
wordlist="$2"

for sub in "$(cat ${wordlist})";do
  host "${sub}"."${dominio}" | grep "has address"
done

Uso:
user@localhost:~$ bash sub.sh "dominio.com" list.txt


Explicação:

O script inicia definindo o hashbang (shebang), que identifica qual interpretador de shell será utilizado para executar o código.

Logo em seguida, utiliza o parser de argumentos do próprio bash para armazenar a URL e a wordlist recebidas no terminal em duas variáveis (`url` e `wordlist`).

Na sequência, o loop `for` percorre cada linha da wordlist utilizando a substituição de comando `$(cat ...)` para armazenar o termo atual na variável `sub`. Para cada iteração, o comando `host` realiza a consulta DNS concatenando o subdomínio ao domínio principal, enquanto o `grep "has address"` filtra a saída exibindo apenas os subdomínios válidos que resolveram para um endereço IP.



Pesquisa Reversa de IPS

Como vimos no tópico anterior, é bem fácil descobrir o IP atrelado a um domínio ou subdomínio.

Podemos seguir a lógica inversa: em vez de tentarmos descobrir o IP a partir de um DNS, faremos o processo contrário. Por meio de uma consulta reversa, conseguimos descobrir o domínio (ou subdomínio) atrelado a um determinado endereço IP.

pauloxc6@github-pages

#!/usr/bin/env bash

ip="$1"

for i in {1..254};do
  host "$ip"."$i"
done

Uso:
user@localhost:~$ bash revip.sh "1.1.1"


Explicação:

O script realiza uma varredura de DNS reverso (Reverse DNS Lookup) em um bloco /24 de endereços IP.

Ele recebe como argumento os três primeiros octetos de uma rede (ex: 1.1.1) e armazena o valor na variável ip. Em seguida, o loop for itera do número 1 ao 254, completando o quarto octeto.

A cada repetição, o comando host faz uma requisição PTR consultando o endereço IP montado (ex: 1.1.1.1 até 1.1.1.254) para retornar o Nome de Domínio Totalmente Qualificado (FQDN) associado a cada host daquela sub-rede.



Transferêcia de zona DNS com bash

A transferência de zona DNS é um dos mecanismos disponíveis para administradores replicarem bases de dados DNS entre servidores. Esse processo utiliza o protocolo TCP na camada de transporte e funciona na estrutura cliente-servidor.

pauloxc6@github-pages

#!/usr/bin/env bash

domain="$1"

for server in $(host -t ns "${domain}" | cut -d " " -f4);do
  host -l "${domain}" "${server}"
done

Uso:
user@localhost:~$ bash trans.sh "domain.com"


Explicação:

O script automatiza a tentativa de transferência de zona (AXFR) consultando todos os servidores de nome (NS) autoritativos de um domínio target.


Primeiro, ele recebe o alvo como argumento (ex: domain.com) e armazena o valor na variável domain.


Dentro do loop for, o comando host -t ns "${domain}" consulta os registros Name Server do domínio. Em seguida, o cut -d " " -f4 trata a saída para extrair apenas os endereços dos servidores DNS retornados.


A cada repetição, o script executa host -l "${domain}" "${server}", enviando uma requisição de transferência de zona (parâmetro -l) para cada servidor encontrado. Se o servidor de nome estiver vulnerável (com a transferência de zona mal configurada), ele responderá listando todos os registros DNS contidos naquela zona de uma só vez.



Descobertas de ips dentro de uma rede

Há momentos em que estamos dentro de um servidor ou host que não possui as ferramentas necessárias para o nosso uso. Nessas situações, você como administrador precisa saber se virar com o Bash.


Uma forma simples de descobrir hosts ativos na rede é através do comando ping, com o qual conseguimos mapear a sub-rede.


pauloxc6@github-pages

#!/usr/bin/env bash

network="$1"

for i in {1..254};do
  ping -c 1 "$network"."$i" &
done | grep "64 bytes"

Uso:
user@localhost:~$ bash discover.sh "192.168.1"


Explicação:

O script realiza uma varredura de rede (Ping Sweep) enviando pacotes ICMP para identificar quais hosts estão ativos em um bloco /24.


Ele recebe os três primeiros octetos da sub-rede como parâmetro no terminal (ex: 192.168.1) e armazena na variável network.


O loop for percorre de 1 a 254 completando o endereço IP. A cada iteração, o comando ping -c 1 envia apenas um pacote de eco para o host correspondente.


Ao adicionar o caractere comercial (&), cada instrução de ping é executada em segundo plano (background process), permitindo testar todos os 254 endereços de forma assíncrona e rápida. Por fim, o grep "64 bytes" filtra a saída e exibe na tela somente as respostas obtidas dos hosts que estão online.



Port Scan com bash

Uma das ferramentas mais importantes que podemos ter em nosso arsenal é o port scanner. Temos o famoso Nmap para essa finalidade, mas se você estiver em um cenário onde não o tem disponível, precisará construir um rapidamente.


pauloxc6@github-pages

#!/usr/bin/env bash

host="$1"

for port in {1..65535};do
  (echo >/dev/tcp/"$host"/"$port") 2>/dev/null && echo "[+] Porta $port aberta"
done

Uso:
user@localhost:~$ bash pscan.sh "192.168.1.1"


Explicação:

O script realiza uma varredura de portas TCP (Port Scan) utilizando o pseudo-dispositivo interno do próprio Bash para testar conexões sem a necessidade de ferramentas externas como nmap ou nc (netcat).


Ele recebe o endereço IP ou nome do host como parâmetro no terminal e armazena o valor na variável host.


O loop for percorre o intervalo de portas de 1 a 65535. A cada iteração, a instrução echo >/dev/tcp/"$host"/"$port" tenta abrir um socket TCP com o destino naquela porta específica.


O redirecionamento 2>/dev/null descarta todas as mensagens de erro (STDERR) geradas quando uma porta está fechada ou filtrada. O operador lógico && faz com que a mensagem de porta aberta só seja impressa na tela se a conexão TCP for estabelecida com sucesso (retorno 0 do Bash).
